# V1.2 Change Spec — Audio Summing Resistors

**Date:** 2026-03-13
**Change:** Add 4 series resistors on speaker lines for safe BTL parallel mono summing
**Priority:** Should fix — prevents potential gain mismatch issues when paralleling BTL amplifier channels

---

## Problem

In Batman mode, SW4 directly parallels the sound board's L and R BTL amplifier outputs onto a single JAMMA speaker. Without series resistors, gain mismatch between the two channels causes one channel to fight the other — excess current, distortion, and potential amplifier stress. The TI LM3886 application note specifies 0.1 ohm 3W series resistors as mandatory for paralleled BTL outputs.

## Solution

Add one series resistor on each of the four sound board speaker lines, between J4 and SW4. These act as current-sharing ballast resistors that isolate the two channels from each other while passing audio to the speaker with negligible loss.

---

## Components

| Designator | Value | Power | Tolerance | Package | Notes |
|------------|-------|-------|-----------|---------|-------|
| R1 | 0.22 ohm | 1W | 5% | Axial through-hole | Series on SB_L+ |
| R2 | 0.22 ohm | 1W | 5% | Axial through-hole | Series on SB_L- |
| R3 | 0.22 ohm | 1W | 5% | Axial through-hole | Series on SB_R+ |
| R4 | 0.22 ohm | 1W | 5% | Axial through-hole | Series on SB_R- |

### Why 0.22 ohm / 1W

- Must be much less than speaker impedance (8 ohm) to avoid significant power loss: 0.22 / 8 = 2.75% loss — negligible.
- Must be large enough to provide current sharing between channels. 0.22 ohm is a standard value in the range recommended by amplifier app notes (0.1–0.47 ohm).
- 1W rating provides plenty of margin for arcade speaker power levels. At 1A peak through the resistor, dissipation is only 0.22W.
- Through-hole axial to match the rest of the board (zero SMD rule).

### Sourcing

Search DigiKey or Mouser for: **0.22 ohm, 1W, through-hole axial resistor**

Likely types: metal oxide or wirewound (metal film uncommon at this value). Common series:
- Yageo FMP100 (1W flame-proof metal film)
- Vishay/Dale RS series (wirewound)
- KOA Speer RSF1JT (metal oxide)

## Schematic Changes

Break each SB net into two segments with a resistor in between:

| Net (current) | Break into | Resistor |
|---------------|-----------|----------|
| SB_L+ (J4 pin 4 → SW4 pin 3) | SB_L+_J4 → R1 → SB_L+ → SW4 pin 3 | R1 |
| SB_L- (J4 pin 3 → SW4 pin 6) | SB_L-_J4 → R2 → SB_L- → SW4 pin 6 | R2 |
| SB_R+ (J4 pin 2 → SW4 pin 9) | SB_R+_J4 → R3 → SB_R+ → SW4 pin 9 | R3 |
| SB_R- (J4 pin 1 → SW4 pin 12) | SB_R-_J4 → R4 → SB_R- → SW4 pin 12 | R4 |

Each net currently connects only J4 and SW4 (no other components), so the break is clean — just insert the resistor symbol in series on each wire in the schematic.

## PCB Layout Changes

### Current routing
All four SB traces run on inner layers (Inner1 and Inner2) from J4 to SW4:
- SB_L+: Inner1, ~28mm
- SB_L-: Inner2, ~25mm
- SB_R+: Inner2, ~15mm
- SB_R-: Inner1, ~13mm

### Resistor placement
Place R1–R4 **below J4** (toward the tab edge). There is ~13mm of clear space between J4 (Y=-64.1mm) and the board outline (Y=-77mm), with no components in the way.

Suggested layout — 4 resistors in a vertical column below J4, aligned with J4's 3.96mm pin pitch:

```
        ┌─────────────── JAMMA EDGE ───────────────┐

                    ...other components...

          J4:  [pin4] [pin3] [pin2] [pin1]
                 |       |      |      |
          R1:  [===]   [===]  [===]  [===]  :R4
                 |       |      |      |
                 └── traces to SW4 pins ──┘

        └─────────────── TAB EDGE ─────────────────┘
```

### Footprint
Standard axial resistor, 1W (body ~11mm × 4.5mm). Use 10mm lead spacing (pitch) if available, or 12.7mm (0.5") for easier hand soldering. Pad diameter 1.2mm, hole 0.8mm.

### Routing procedure in EasyEDA Pro
1. Backup the .eprj file
2. Remove copper pours (Tools → Copper Manager)
3. Unroute the 4 SB nets (select each trace and delete, or Route → Unroute by net)
4. Add R1–R4 to schematic in series on each SB wire
5. Update PCB from schematic
6. Place R1–R4 footprints below J4
7. Route: J4 pad → short trace → R pad 1 | R pad 2 → trace to SW4 (can reuse inner layers)
8. Rebuild copper pours (Shift+B)
9. Run DRC — should be 0 errors

---

## What Does NOT Change

- ST-V mode is unaffected — the resistors are only in the SB_* nets, which are the Batman-mode throw pins on SW4. In ST-V mode, SW4 connects STV_SPK± to CAB_SPK± directly (no resistors in that path).
- Line-level audio path (RV1, J7, J8, J9, J10) is completely separate — different nets, different components.
- All other connectors, switches, and power distribution unchanged.
- Board dimensions unchanged.
